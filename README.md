# Amman Crest Academy

Frontend-only school website built with Vite + React + TypeScript.

## Live site

**https://forkslove1-spec.github.io/amman-crest-academy/**

Public HTTPS · no login · responsive across desktop and mobile · SPA section routes.

## Develop locally

```bash
npm install
npm run dev
```
